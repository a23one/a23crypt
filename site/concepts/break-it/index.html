Why nothing gets through.

Defences overlap on purpose, so an attack has to beat several of them at once.

Two authentication tags

Poly1305 on the outside and GCM on the inside. Any change to a sealed byte fails at least one of them.

Position is part of the seal

Each frame's tags cover its index, whether it is the final frame, the flags and the chunk size. Reordered, duplicated or relabelled frames don't verify.

Keys are per record, per encryption

Subkeys come from HKDF over the record key and a fresh salt. A frame lifted from another record, or another seal of the same record, belongs to different keys.

A final frame is required

Decryption refuses a stream that ends without a frame marked final, so cutting the tail off is detected, not silently accepted.

Sizes are capped before allocation

Length prefixes over 128 KiB are rejected before any memory is reserved. Decompression stops at the chunk size, which defuses zstd bombs.

Errors don't leak which layer failed

The library raises a uniform DecryptionError. This page names the layer to show the cascade working; your logs won't.

Use it.

Four keyword-only functions. Bytes up to 1 MiB, or streams of any size in constant memory. Python 3.14 and later.

import os, a23crypt

server_key = os.urandom(32)   # held by your server
client_key = os.urandom(32)   # held by your user

sealed = a23crypt.encrypt(
    b"Meet at the north gate at six.",
    server_key=server_key,
    client_key=client_key,
    record_key=b"msg-0417",
)

try:
    a23crypt.decrypt(sealed, server_key=server_key,
                     client_key=client_key, record_key=b"msg-0417")
except a23crypt.A23CryptError:
    ...  # IntegrityError, DecryptionError, ...

What it won't stop.

You found one already if you ran the replay attack. Here are the rest.

Replays

An untouched ciphertext opens every time. Put a nonce or timestamp in the plaintext and track it.

A leaked key

If one party's key leaks, that party's protection is gone. The other key still holds.

Attacks in transit

This is at-rest encryption. Use TLS on the wire.

Weak passwords

Stretch passwords with Argon2id first and pass the 32-byte result.

Memory scraping

Decrypted bytes stay on the Python heap and are not wiped.

Half-written streams

A failed decrypt_stream may leave earlier chunks behind. The bytes API is atomic.
