a23crypt landing page concepts

Three directions. Each runs a JavaScript port of the a23crypt wire format, so every ciphertext on these pages is real and opens in Python.

  1. Two keys

    Split custody as the whole identity. The page is split down the middle between server and client. Take either key away and watch the record stay shut.

  2. Strata

    Defence in depth as a geological cross-section. Scroll down through the real bytes of your message at each layer until you reach the plaintext as bedrock.

  3. Break it

    A tamper lab. The hero is a ciphertext as a grid of bytes. Flip any bit or run the README's attacks and see which defence catches each one.
